# AI Usage Contract

## 1. Purpose

This document defines responsible and transparent use of artificial intelligence (AI) tools in the Student Information System project.

AI may assist with learning, requirements analysis, design, programming, testing, and documentation. It must support human work rather than replace human judgment.

## 2. Acceptable AI Usage

AI tools may be used to:
- Understand project requirements and explore possible solutions.
- Brainstorm designs and improve code readability.
- Generate code suggestions, test cases, and debugging ideas.
- Improve documentation, comments, and explanations.
- Support learning and understanding of programming concepts.

AI-generated content is a suggestion, not an automatically trusted solution.

## 3. Human Responsibility

The person using AI is responsible for all work they submit.

Contributors must understand the changes they make, ensure they meet project requirements, and take responsibility for correctness, quality, and compliance with project policies.

AI assistance does not transfer responsibility from the contributor to the AI tool.

## 4. Verification of AI Outputs

Before using AI-generated content, contributors must:
- Check its accuracy and relevance to the task.
- Review code for correctness, readability, and compatibility.
- Run appropriate tests and inspect their results.
- Check for security, privacy, and reliability concerns.
- Correct or reject suggestions that are inaccurate, unsafe, or unsuitable.

Unverified AI output must not be treated as confirmed or production-ready.

## 5. Confidentiality and Data Protection

Contributors must not submit confidential project information, private personal data, credentials, or other restricted information to AI tools unless explicitly authorized under applicable project policies.

Never commit API keys, passwords, access tokens, private keys, or other secrets to the repository. Use appropriate environment variables or approved secret-management mechanisms when credentials are required.

If a secret is accidentally exposed, report it promptly and follow the appropriate revocation and remediation process.

## 6. Review of AI-Assisted Code

All AI-assisted code must undergo the same review as other code.

Contributors must understand the code, verify its behaviour, run relevant tests, and address review feedback before merging. AI-generated code must not bypass project review requirements.

## 7. Recording AI Assistance

Significant AI assistance must be recorded in `AI_USAGE_LOG.md`.

The record should describe the tool used, purpose, task, output incorporated, human reviewer, verification method, and related GitHub issue or pull request.

Do not include confidential information, credentials, or sensitive prompts in the log.

## 8. Compliance

Contributors are expected to follow this contract, the repository's contribution guidelines, and applicable security and privacy requirements.

The human contributor remains accountable for the work submitted, regardless of the amount of AI assistance used.
