# AI Usage Log

## Purpose

This file records significant AI assistance used during the development and maintenance of the Student Information System.

Contributors should record AI assistance when generated content meaningfully contributes to requirements analysis, design, programming, testing, or documentation.

Do not record secrets, credentials, confidential information, or sensitive prompts.

## Required Fields

| Field | Description |
|---|---|
| Date | Date the AI tool was used, preferably in YYYY-MM-DD format |
| AI tool | Name of the AI tool or model used |
| Purpose | Reason for using the tool |
| Task | Work or problem the tool helped with |
| Output used | Brief description of the AI-generated content incorporated |
| Human reviewer | Person responsible for reviewing the output |
| Verification method | How the output was checked, tested, or validated |
| Related GitHub Issue/PR | Link or reference to the associated issue or pull request, if applicable |

## Log Template

Copy this row for each significant AI-assisted task.

| Date | AI tool | Purpose | Task | Output used | Human reviewer | Verification method | Related GitHub Issue/PR |
|---|---|---|---|---|---|---|---|
| YYYY-MM-DD | Tool name | Purpose | Task description | Summary of incorporated output | Reviewer | Tests, manual review, or other verification | Issue/PR link or N/A |

## Review Requirements

The human contributor must verify AI-assisted work before it is submitted or merged. The log records the verification method and the person responsible for review.

An AI-generated suggestion alone does not establish that the work is correct, secure, or complete.
